We are building a comprehensive "Vehicle Repair Shop Management System" from scratch.

Project Overview & Tech Stack

Stack: MongoDB, Express.js, React, Node.js (MERN)

Goal: A centralized platform handling customer bookings, multi-branch management, internal operations, and financials.

User Roles

Customer: Books services, makes online payments, and leaves feedback.

Staff/Mechanic: Views assigned repairs and updates service statuses.

Branch Manager: Manages local inventory, local staff, and daily branch operations.

Super Admin: Oversees regional stores, cross-branch data, and system-wide salary processing.

Core Scope & Features

Vehicle Repair/Service Booking: Customers can select service types, pick available time slots, and track repair status.

Staff Management: Role-based access control (RBAC), employee profiles, task assignment, and attendance.

Inventory Management: Track auto parts, get low-stock alerts, and manage branch-specific inventory.

Regional Store Management: Support for multiple physical branches. Data, staff, and inventory must be filterable by region/store.

Salary Management: Calculate payroll based on roles, hours, or commission, and manage payslips.

Online Payment Service: Secure checkout for completed services (e.g., via Stripe) and invoice generation.

Customer Feedback: Post-service rating and review system to track branch and staff performance.
